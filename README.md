# E-commerce Events Analysis (Product Analytics)

Пет-проект по анализу пользовательского поведения и продуктовых метрик на основе **E-commerce Events Dataset**, выполненный для отбора на интенсив **«Продуктовый аналитик, Т-Банк»**.

---

## TL;DR

Проанализировал пользовательское поведение в e-commerce:

* посчитал ключевые продуктовые метрики (DAU, ARPU, retention)
* проанализировал возвраты и распределение пользователей по их количеству
* выявил, что треть пользователей (33%) совершают 3 и более возвратов, а без возвратов — только 13%
* общий churn составляет **20%**
* сформулировал продуктовые инсайты и гипотезы для снижения возвратов и оттока

---

## 📌 Цель проекта

Понять, как пользователи взаимодействуют с e-commerce продуктом, и выявить точки роста через анализ:

* пользовательской активности
* продуктовых метрик
* возвратов и оттока (churn)

---

## 🗂 Данные

**Источник:** E-commerce Events Dataset (CSV)

| Колонка          | Описание                   |
| ---------------- | -------------------------- |
| customer_id      | Уникальный ID пользователя |
| purchase_date    | Дата и время события       |
| product_category | Категория товара           |
| product_price    | Цена товара                |
| quantity         | Количество                 |
| total            | Итоговая сумма покупки     |
| payment_method   | Способ оплаты              |
| customer_age     | Возраст                    |
| returns          | Возврат товара (0/1)       |
| churn            | Уход пользователя (0/1)    |

**Подготовка данных:**

* `total` приведён к `product_price * quantity`
* NULL в `returns` заменены на 0
* даты приведены к `TIMESTAMP`
* данные загружены в PostgreSQL через DataGrip

### Блок 1. Базовые метрики

* Всего событий: **250 000**
* Среднее число событий на пользователя: **5.03**

**Вывод:** пользователи демонстрируют стабильный уровень вовлечённости, что позволяет переходить к более глубокой продуктовой аналитике.

---

### Блок 2. Активность пользователей (DAU)

* Рассчитан DAU (Daily Active Users) по дням
* Используется для анализа динамики активности и выявления аномалий

**Интерпретация:**

* рост DAU → рост интереса к продукту
* падение DAU → возможные проблемы с удержанием или внешние факторы

---

### Блок 3. Продуктовые метрики

Реализованы в SQL:

* Total Revenue
* ARPU
* средний чек
* топ-10 категорий и товаров
* базовый retention / повторные покупки

(см. [`sql/base_metrics.sql`](ecommerce-events-analysis/sql/base_metrics.sql))

---

### Блок 4. Анализ возвратов

Распределение пользователей по количеству возвратов
(доля от всех уникальных пользователей):

* **0 возвратов — 12.98%**
* **1 возврат — 27.02%**
* **2 возврата — 26.94%**
* **3 возврата — 18.07%**
* **4 возврата — 9.48%**
* **5+ возвратов — 5.51%**

**Ключевые наблюдения:**

* ~54% пользователей совершают 1–2 возврата
* ~33% пользователей имеют 3 и более возвратов
* пользователи с ≥3 возвратами — потенциальная зона риска

---

### Блок 5. Churn (отток пользователей)

Процент пользователей с `churn = 1`:

* **20.01%** от всех уникальных пользователей

**Важно:**
В датасете churn — бинарный признак на уровне пользователя (если пользователь ушёл, `churn=1` стоит на всех его событиях).
Поэтому churn рассчитывается **на уровне пользователя** (`MAX(churn)` по `customer_id`), а не как момент времени ухода.

---

## 🔎 Инсайты и рекомендации

* Основная зона риска — пользователи с **2+ возвратами**
* Возможные причины: качество товаров, ожидания, логистика
* Рекомендуемые продуктовые гипотезы:

  * анализ SKU и категорий с наибольшим числом возвратов
  * персональные офферы для пользователей с 1–2 возвратами
  * отдельные сценарии удержания для сегмента 3+ возвратов
  * мониторинг доли пользователей с ≥3 возвратами как продуктовой метрики

---

## ⚠️ Ограничения анализа

* churn не имеет временной привязки
* невозможно определить, после какого именно возврата пользователь ушёл
* датасет синтетический, выводы носят демонстрационный характер
